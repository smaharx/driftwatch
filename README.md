# DriftWatch Dashboard

React + TypeScript + Tailwind + Recharts

## Stack
- React 18 + TypeScript
- Vite (build tool)
- Tailwind CSS (styling)
- Recharts (drift timeline charts)
- Axios (API client)
- React Router (navigation)

## Pages
- / — overview dashboard
- /models — model registry
- /models/:id — model detail + drift timeline
- /alerts — alert log
